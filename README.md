# 拼豆管理 · 安卓安装包

本仓库仅提供签名 APK、校验文件和更新清单，不保存业务源代码、签名密钥或客户数据。

[下载最新版 APK](https://github.com/lizardsking189/pindou-android-releases/releases/latest)

支持 Android 8.0 及以上，需要联网。旧版用户请直接覆盖安装 1.0.2 或以上版本，不用卸载旧版。

安装后启动时会自动检查新版，也可以使用“更多 → 检查更新”。确认下载后在 App 内下载并校验，打开安卓系统安装确认页。首次需要允许“拼豆管理”安装应用，最后仍需用户确认安装，不支持静默安装。

网页功能继续在线更新。安装包更新不更改服务器上的顾客计时、会员和余额。

App 更新清单位于根目录 `update.json`。新的 Release 安装包先发布，清单随后更新；不要使用来源不明或签名不同的 APK。
